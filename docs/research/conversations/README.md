# Curated conversation summaries

Save a summary when a conversation contributes a research question, a source, a decision, or a concrete next step. Use the [template](template.md) and name the file `YYYY-MM-DD-topic.md`. Link it here after review.

Work from a user-provided excerpt, an explicitly shared conversation, or a chat available in the current session. State which part you reviewed and leave unseen portions unverified. A conversation can document a decision or an idea. Check factual claims against the primary source before citing them as evidence.

Use short paraphrases. Keep private chat links, transcript exports, personal data, and private feedback in the local workspace. Link a separate [research note](../note-template.md) for any evidence review and update [project status](../../../PROJECT_STATUS.md) when an agreed decision changes scope.
