# Approved supplementary product requirement

## User-Controlled Scientific Validation

When the system detects an inconsistency, ambiguity, or potentially incorrect instruction in an uploaded educational document, it should notify the user and explain the issue.

The user should be offered the option to stop the generation process for review or continue with the generation.

If the user chooses to continue, the system should aim to produce the requested interactive experience using disclosed, scientifically justified corrections where appropriate. Any unresolved inconsistencies, assumptions, or unverified content should remain clearly identified.

The original document should remain unchanged, and the generated experience should include a record of relevant corrections and validation results.

A generated experience must not be presented as scientifically validated unless the applicable validation requirements have been satisfied.
