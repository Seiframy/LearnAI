## What it could add to LearnAI

The closest fit is building and testing a room. A developer could give Claude Code a prompt and a running Unreal project. The skill tells Claude how to discover editor tools using Model Context Protocol (MCP), a way for the assistant to call tools in another program. Those tools can return information about objects in the room, edit the level or its visual scripts, and report results from existing Unreal automation tests. [Skill](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/skills/unreal-mcp/SKILL.md) · [Epic's Unreal MCP documentation](https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor?application_version=5.8)

LearnAI's first planned room uses Three.js and TypeScript in the browser. The existing MLP Lab is a hand-built React and TypeScript prototype. The plugin's inputs and outputs are Unreal editor commands and Unreal project state. I found no path in the reviewed source for loading LearnAI's mission format, checking answers against PDF pages, or running the browser playthrough. A separate Unreal prototype could use it for authoring, but the current plan has no such milestone. ## How to set it up

1. Use a disposable Unreal project and an editor build that includes `ModelContextProtocol` and `AllToolsets`. Epic documents the experimental integration in Unreal Engine 5.8. The plugin docs give no exact minimum Claude Code version or compatibility table for plugin version `3.1.2`. Install and authenticate Claude Code using Anthropic's setup guide. The hook needs Bash on `PATH`. On Windows, Epic documents Git Bash or WSL. [Epic release notes](https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-5-8-release-notes) · [Claude Code setup](https://code.claude.com/docs/en/setup) · [Upstream README](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/README.md)
2. In Unreal Editor, enable **Unreal MCP** and **All Toolsets** under **Edit → Plugins** and restart when prompted. Open the editor console, run `ModelContextProtocol.StartServer`, then run `ModelContextProtocol.GenerateClientConfig ClaudeCode`. The default connection is `http://127.0.0.1:8000/mcp`. The generated `.mcp.json` goes beside the `.uproject` for an installed editor or at the workspace root alongside `Engine/` for an engine source build. The local server requires no API key. [Pinned setup instructions](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/skills/unreal-mcp/references/setup.md) · [Epic's Unreal MCP documentation](https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor?application_version=5.8)
3. Start Claude Code with `claude` from the folder containing the generated config. In Claude Code, add the official marketplace only if it is missing, then install the plugin. The install command downloads the marketplace version. The downloaded Bash hook runs when a Claude session starts, resumes, or clears. [Upstream README](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/README.md) · [Hook configuration](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/hooks/hooks.json)

   ```text
   /plugin marketplace add anthropics/claude-plugins-official
   /plugin install unreal-engine-skills-for-claude-code@claude-plugins-official
   ```

4. Check the Installed tab in `/plugin` and the connection in `/mcp`. Ask Claude to use the `unreal-mcp` skill to list objects, called actors, in the current level. Compare the results with the editor. This is the direct connection path. Epic documents an optional proxy that can reconnect across editor restarts. The engine also documents generating a Codex client config, which connects to the editor separately from this Claude Code package. [Verification and proxy instructions](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin/blob/0e27bde2b55c5d3f6948532f4296aaa3654d8f4b/skills/unreal-mcp/references/setup.md)
