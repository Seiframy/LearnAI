## What it could add to LearnAI

The closest fit is setting up the browser room. Give the agent a small Three.js project and ask it to build a scene that resizes with the window. The `threejs-scene-setup` skill gives it a worked scene, camera, drawing loop, and a check for a blank canvas. The router is a set of instructions that uses signals such as a `three` dependency to choose relevant guidance. LearnAI already plans to use Three.js. The possible benefit is fewer setup mistakes and less time finding the right example. [Scene skill](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/skills/web-engines/threejs-scene-setup/SKILL.md) · [Router](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/router/SKILL.md) · [LearnAI seminar plan](../../presentations/seminar-draft.md)

The reviewed browser examples help draw the room. LearnAI would still supply its own lesson rules, mission validation, and playthrough checks. A direct comparison with Three.js's official setup guide would show whether the extra instructions help. ## How to set it up

1. In an isolated test project's root, use Node.js `22.20` or newer for the upstream installer. Run `npx skills add gamedev-skills/awesome-gamedev-agent-skills -a codex --skill threejs-scene-setup` for a focused trial. This downloads and runs an external installer. For the exact reviewed revision, copy `skills/web-engines/threejs-scene-setup/` from the pinned source to `.agents/skills/threejs-scene-setup/`. [Installation guide](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/docs/INSTALLATION.md) · [README](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/README.md)
2. Open the test project in Codex. Check `/skills` for the new skill and invoke `$threejs-scene-setup`. The example targets Three.js r187 (`0.187.0`). Keep an existing project's pinned version. To try the documented browser-only example, use its import-map and module snippets together and serve them over local HTTP. The import map fetches Three.js from jsDelivr. A local bundler with `three` installed can use the same imports. [Scene skill](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/skills/web-engines/threejs-scene-setup/SKILL.md) · [Version table](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/docs/VERSION-SUPPORT.md)
3. Open the page in a browser. Check that the sample mesh appears and keeps its proportions when the window changes shape. To try automatic routing as well, install `router/` as `.agents/skills/router/` and use a test project whose package declares `three`. The router can only load skills the agent can access. [Router](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/router/SKILL.md) · [Engine detection](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/c6ca6c41c839b68319ffc08430b99ab768debc32/router/references/engine-detection.md)
